# Backend Lab

This folder contains the practical experiments completed as part of the Backend Development course.

The experiments focus on implementing backend concepts using different technologies, frameworks, databases, and server-side tools.



## 🛠️ Technologies Used

- **Node.js** – Server-side JavaScript runtime
- **Express.js** – Web framework for Node.js
- **EJS** – Server-side templating engine
- **MongoDB** – NoSQL database
- **Mongoose** – ODM for MongoDB
- **PostgreSQL** – Relational database
- **Flask** – Python web framework
- **JavaScript** – Backend programming
- **Python** – Backend development
